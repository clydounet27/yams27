Ajouter des parties

Connectez-vous avec votre compte Google pour ajouter des parties.

Clé IA à enregistrer (une seule fois). La lecture des photos passe par une clé Gemini gratuite :

  1. Ouvrez aistudio.google.com/apikey avec votre compte Google.
  2. Cliquez sur « Créer une clé API » (Create API key), choisissez le projet Yam's si on vous le demande, puis copiez la clé en entier (elle commence par exemple par AIza ou AQ.).
  3. Collez-la ici. Elle est gardée dans votre base Firebase, lisible seulement par votre compte.

Une à quatre feuilles de score par photo, bien de face. Les grilles sont lues automatiquement, vous vérifiez ensuite.
