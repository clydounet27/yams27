# Carnet de Yam's

Scores des parties de Yam's entre R, G et JM.
Chaque envoi sur la branche main republie automatiquement le site sur Firebase Hosting.

## Données

- `donnees/yams_parties.csv` : une ligne par joueur et par partie.
- `donnees/yams_data.json` : base complète utilisée par l'appli.
- `donnees/build.py` + `donnees/app_template.html` : génèrent la base et la page `public/index.html`.
